# BlockAid

Volunteer storm-readiness for cities, part of the CivicPlexus family. Residents adopt storm drains, fire hydrants and priority sidewalks; Public Works gets a live triage dashboard during severe weather. Any city can start its own space.

## What it does

- **Resident map** — adopt an asset, mark it cleared, or flag it for a city crew, with photos.
- **Neighborhoods** — staff set them up as simple names or from a GeoJSON boundary file; residents get a map for their own area, and everything still adds up citywide.
- **Community page** — storm-readiness by neighborhood, impact totals, teams, badges and a printable volunteer certificate.
- **Public Works dispatch** — storm mode, a priority triage queue, and a CSV export for 311 or work-order systems.
- **AI report helper** (optional) — suggests the reason for a problem and details worth adding. The app runs fully without it; see the self-hosting guide.
